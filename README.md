# Contact Form with Validation

This project is a Contact Form developed using HTML5, CSS3, and JavaScript. It allows users to enter their details and validates the input before form submission.

## Features

* User-friendly contact form
* Validation for empty fields
* Phone number length verification
* Interactive alert messages
* Modern and responsive user interface
* Clean and structured design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Learning Outcomes

Through this project, I learned how to perform client-side form validation, handle user input, improve user experience, and implement interactive functionality using JavaScript.

## Project Goal

The goal of this project was to understand form handling and validation techniques while building a responsive and user-friendly web application component.
